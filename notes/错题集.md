## 错题明细

### 2026-09-08 Day 1 — 数组与哈希

**1. 两数之和**（做对了，但 dict 机制混淆）
- **错误原因**：对 Python dict 的 `if rest in memory:` 语义混淆，不确定检查的是键还是值
- **正确思路**：`in` 永远检查字典的**键（Key）**，与值无关。存储时用 `memory[num] = i`（值→索引），查询时 `if rest in memory` 就是查"这个值有没有出现过"
- **所属框架**：哈希
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**283. 移动零**
- **错误原因**：不是最优解；漏了"快慢指针相同"的情况（slow == fast 时交换自己，白交换一次）
- **正确思路**：慢指针指向下一个非零元素应放的位置，快指针扫描。`if nums[fast] != 0: 交换 nums[slow], nums[fast]; slow += 1`。可加 `if slow != fast` 判断跳过自我交换
- **所属框架**：双指针
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**11. 盛最多水的容器**
- **错误原因**：忘记取全局最大值 `max_area = max(max_area, area)`
- **正确思路**：左右指针向中间逼近，每步计算当前面积并更新全局最大，然后**移动较矮的一边**（贪心：矮边是瓶颈，动高边不可能增大面积）
- **所属框架**：双指针
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**49. 字母异位词分组**
- **错误原因**：完全没思路，看得懂答案；对 `sorted(str)` 的结果和视图不理解
- **正确思路**：异位词排序后完全相同。用 `"".join(sorted(s))` 做 key，把原词 append 进对应分组
- **关键坑**：`sorted(s)` 返回的是**字符列表**（list），不是字符串。list 不可哈希，不能直接做 dict 的 key，必须 `"".join()` 转回字符串
- **所属框架**：哈希
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**128. 最长连续序列**
- **错误原因**：完全不知道思路，看不懂答案；不会分析复杂度
- **正确思路**：全部数字放进 HashSet。**只从序列起点开始数**：`if x - 1 not in set` 时 x 才是某段连续序列的最左端。为什么剪枝？x-1 存在说明 x 在别人序列的中段，从它数出来的序列一定被截短，数了也白数。起点确定后，`while x + 1 in set` 不断计数，更新全局最长
- **复杂度**：O(n)。每个数最多被访问两次（作为起点向后数一次 + 被跳过时查一次），不是 O(n²)
- **所属框架**：哈希
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**15. 三数之和**
- **错误原因**：思路方向对（固定一位 + 找两数和），但漏了双指针的**前提条件：数组必须先排序**
- **正确思路**：先排序。固定 nums[i]，问题变成在剩余区间找两数和 = -nums[i]。双指针 l=i+1、r=n-1 头尾逼近，遇重复跳过（nums[i]==nums[i-1] 跳过外层，nums[l]==nums[l+1] 跳过内层）
- **所属框架**：双指针（排序 + 双指针）
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

### 2026-09-09 Day 2 — 链表

**206. 反转链表**（做对了，但有认知坑）
- **错误原因**：初始化 pre 用了 `ListNode()`（真实节点），导致反转完链表尾部多一个 0 节点
- **正确思路**：pre 必须初始化为 `None`。**None 是链表的结束标志，ListNode() 是实实在在的节点**。用 ListNode() 当 pre 会凭空多出一个假节点
- **所属框架**：链表
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**21. 合并两个有序链表**
- **错误原因**：想不到用新指针（tail）穿针引线；对"新建链表 vs 改原链表"的空间操作理解不清
- **正确思路**：**不需要复制任何节点**。dummy 是唯一的占位节点，tail 是游标。谁小接谁——把节点从原链上"拆下来"接到 tail 后面。节点还是那些节点，只是 next 指向变了。空间复杂度 O(1)
- **所属框架**：链表（虚拟头节点）
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**19. 删除链表的倒数第 N 个结点**
- **错误原因**：最后 `return head`，当头节点被删除时返回错误
- **正确思路**：一律 `return dummy.next`。dummy 永远指向真正的头，无论删的是不是头节点都安全。这就是虚拟头节点的意义：统一处理头节点和非头节点
- **所属框架**：链表（虚拟头节点）
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**234. 回文链表**
- **错误原因**：①快慢指针循环条件漏了 `f.next` 非空判断；②比较循环写成 `while p1`（忘了 p1、p2 共享节点）；③反转三指针不熟练
- **正确思路**：= 876（找中点）+ 206（反转）。快慢指针找中点（`while fast and fast.next`），反转后半段，然后 p1=head、p2=反转后的头，**`while p2` 比较**。为什么不能 while p1：中间节点被反转后，p1 的链和 p2 的链在中间相连，p1 会先走到 None，用 p2 判断才正确
- **所属框架**：链表（快慢指针 + 反转）
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

### 2026-09-10 Day 3 — 栈与队列

**20. 有效的括号**（思路对，两个知识点坑）
- **错误原因**：①误以为 `is` 和 `==` 等价；②分支里忘记处理栈空的情况
- **正确思路**：
  - `is` 比较**内存地址**，`==` 比较**值**。字符串相等判断永远用 `==`（`is` 只是碰巧对小整数/短字符串缓存有效，不可依赖）
  - 弹出前必须判空：`if not stk or stk.pop() != "(": return False`。`not stk` 短路保护：栈空时直接 False，不会对空栈 pop 报错
- **所属框架**：栈
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**155. 最小栈**（经提示后写出）
- **错误原因**：忘了 Python 列表 `-1` 索引就是最后一个元素；对"辅助栈同步维护"需要提示才想到
- **正确思路**：两个栈同步 push/pop。辅助栈每次压入 min(当前值, 辅助栈顶)，getMin 就是辅助栈栈顶。`stk[-1]` = 栈顶
- **所属框架**：栈（辅助栈）
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**739. 每日温度**（方法疑问：单调栈是套路还是每道题一个技巧？）
- **错误原因**：不理解单调栈的统一套路，觉得每道题都要现想技巧
- **正确思路**：**单调栈是统一套路，不是每道题一个技巧**。所有"找下一个更大/更小"都是同一个框架：维护单调性 + 弹出即结算。739 = 维护单调递减栈，遇到更大的就弹出并记录下标差
- **所属框架**：单调栈
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**84. 柱状图中最大的矩形**（不会）
- **错误原因**：不知道栈顶被更矮柱子挡住时要弹出结算；不理解为什么用单调递增栈
- **正确思路**：每根柱子能形成的最大矩形 = 高度 × (右边第一根更矮柱子的位置 − 左边第一根更矮柱子的位置 − 1)。维护**单调递增栈**（栈底到栈顶递增）：遇到更矮的柱子 h 时，栈顶柱子的"右边界"确定了（就是 h），左边界是它下面那根 → 弹出并结算面积。最后补一个高度 0 的柱子强制全部出栈
- **所属框架**：单调栈
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

- **复习状态**：✅ 已掌握

**101. 对称二叉树**（思路优化）
- **错误原因**：原思路想用"左中右"和"右中左"两个遍历序列存下来比较。这个思路有坑：必须标记空节点，否则 [1,2,2,null,3,null,3] 这类会误判
- **正确思路**：递归时直接同步比较两棵子树：左.left vs 右.right，左.right vs 右.left。核心想明白：**对称 = 左子树的右分支 对应 右子树的左分支**
- **所属框架**：二叉树（双树同步递归）
- **复习状态**：🔄 复习中
- **三遍刷题法进度**：第一遍✅ 第二遍✅ 第三遍⬜

**543. 二叉树的直径**（最重要的认知突破 ⭐）
- **错误原因**：①漏判断**最长路径可以不经过根节点**（可能在任意子树内部）；②不知道高度和直径是两个不同的返回值，不能在一个递归里同时返回
- **正确思路**：加一个**辅助函数**——helper 返回子树高度（后序 max(左高,右高)+1），同时在递归过程中用全局变量更新 `diameter = max(diameter, 左高+右高)`。主函数调用 helper 后返回全局最大。**高度给父节点用，直径自己在每个节点处结算一次**
- **所属框架**：二叉树（后序 + 辅助函数/全局变量）
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**114. 二叉树展开为链表**（框架不熟）
- **错误原因**：①while 循环找"最右节点"时忘记先保存**原右子树**引用，导致指针混乱找不到拼接目标；②漏了**左子树为空**的情况
- **正确思路**：先展开左右子树（后序），然后：`left = root.left; right = root.right; root.left = None`；若 left 存在 → `root.right = left`，沿 left 链走到最右 → 最右.right = right（原右子树）；若 left 为空 → 直接 root.right = right。**关键：先保存引用再动手**
- **所属框架**：二叉树（后序 + 链表拼接）
- **复习状态**：⬜ 未复习
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜
