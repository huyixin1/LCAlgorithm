## 三遍刷题法

- **第一遍**：白天做题，最多想 15 分钟，不会直接看答案，但看完答案必须默写一遍（合上书写）。
- **第二遍**：当天晚上睡前，把白天题在白纸上只写框架（函数签名 + 关键 3 行逻辑），写不出就标记。
- **第三遍**：3 天后，不看答案，重新做一遍标记的题。

## Day 1：数组与哈希 —— 建立"空间换时间"思维

**目标**：80% 的数组题都在考"哈希表"或"双指针"。

**核心知识点**：
- 哈希表：用 O(1) 查找换取 O(n) 时间，典型是"找一对数满足某条件"
- 双指针：左右指针收缩区间（有序数组）、快慢指针（原地修改）
- 排序 + 双指针：三数之和等去重问题

**习题**：

| 题号 | 题目 | 必须记住的模板 |
|------|------|----------------|
| 1 | 两数之和 | 哈希表查 `target - num` |
| 49 | 字母异位词分组 | 排序字符串做 key，或字符计数 |
| 128 | 最长连续序列 | HashSet + 只找序列起点（剪枝） |
| 283 | 移动零 | 双指针：慢指针指非零该放的位置 |
| 11 | 盛最多水的容器 | 左右指针，谁小谁移（贪心） |
| 15 | 三数之和 | 排序 + 双指针去重（难，先背框架） |

**今天重点**：所有"找一对数"的题，先想哈希；所有"数组操作"的题，先想双指针。

**目标**：链表题 90% 的坑靠两个技巧解决：虚拟头节点（处理头删）、快慢指针（找中点/判环）。

- 快慢指针：快指针走两步、慢指针走一步 → 找中点 / 判环

## Day 3：栈与队列 —— 学会"单调栈"

## Day 4：二叉树基础 —— 这是命门，必须慢下来

**目标**：不要做题，先建立递归框架感。二叉树的所有题 = 遍历框架 + 小问题。

**核心递归框架**：
```python
def traverse(root):
    if not root: return ...
    # 前序：处理当前节点
    left = traverse(root.left)   # 相信左子树能给我结果
    right = traverse(root.right) # 相信右子树能给我结果
    # 后序：根据左右结果，合成当前答案
    return 用 left 和 right 算出的结果
```

**前序 vs 后序判断**：
- 需要子树的信息 → 后序（深度、直径、展开）
- 不需要子树信息 → 前序（翻转、打印）

**习题**：

| 题号 | 题目 | 考点 |
|------|------|------|
| 104 | 二叉树的最大深度 | 后序：max(左深, 右深) + 1 |
| 226 | 翻转二叉树 | 前序：swap(左, 右)，再递归 |
| 101 | 对称二叉树 | 递归比较：左.left vs 右.right |
| 543 | 二叉树的直径 | 后序：左深 + 右深，更新全局最大 |
| 114 | 二叉树展开为链表 | 后序：把左右拉成链，再接上 |

**今天重点**：每道题先问自己"我需要子树的信息吗？"

## Day 5：二叉树进阶 —— BST 和构造

**目标**：BST 是排序数组的树形表达，所有 BST 题都利用"左 < 根 < 右"的性质。

**核心知识点**：
- BST 中序遍历 = 升序序列
- 验证 BST：传区间上下界 (lower, upper)，每个节点必须在区间内
- 构造二叉树 = 分治：找到根 → 递归构造左 → 递归构造右
- LCA（最近公共祖先）：后序遍历，左右各找到一个目标，当前就是 LCA

**习题**：

| 题号 | 题目 | 考点 |
|------|------|------|
| 98 | 验证二叉搜索树 | 中序遍历是递增的 / 传区间上下界 |
| 230 | 二叉搜索树中第K小的元素 | 中序遍历，计数到 K |
| 105 | 从前序与中序遍历序列构造二叉树 | 前序首元素是根，中序找根分左右 |
| 106 | 从中序与后序遍历序列构造二叉树 | 后序尾元素是根 |
| 236 | 二叉树的最近公共祖先 | 后序：左右各找到一个，当前就是 LCA |

**今天重点**：构造二叉树是分治思想，和后面回溯的"做选择→递归→撤销选择"一脉相承。

## Day 6：从二叉树到回溯 —— 接上断层

**目标**：回溯不是新东西，是 N 叉树的后序遍历。

**核心认知**：
- 二叉树递归：dfs(root.left), dfs(root.right) —— 两个子节点
- 回溯：for 选择 in 选择列表 —— 多个子节点
- 递归进去 = 走到子节点（前序做选择）
- 递归返回 = 回到父节点（后序撤销选择）

**回溯框架**：
```python
def dfs(路径, 选择列表):
    if 满足结束条件: 记录结果; return
    for 选择 in 选择列表:
        做选择
        dfs(路径, 新选择列表)
        撤销选择
```

**习题**：

| 题号 | 题目 | 模板 |
|------|------|------|
| 46 | 全排列 | 基础回溯框架，nums 是选择列表 |
| 78 | 子集 | 每次递归都记录，选/不选两种分支 |
| 39 | 组合总和 | 可重复选：递归时 start 不变 |
| 17 | 电话号码的字母组合 | 多叉树，每个数字对应一层选择 |
| 22 | 括号生成 | 剪枝：左括号够才能加右括号 |

**今天重点**：每道回溯题，画一棵决策树。

## Day 7：动态规划入门 —— 从"递归暴力"到"记忆化"

**目标**：DP 不是新东西，是把二叉树/回溯里的重复计算用备忘录存起来。

**认知链**：暴力递归（超时）→ 发现重复子问题 → 加备忘录（记忆化搜索）→ 改写成自底向上（递推 DP）

**核心知识点**：
- 每道 DP 题先写暴力递归版本
- 发现递归树里有大量重复节点时，就懂了为什么需要 DP
- 不要一上来就写 dp[i]

**习题**：

| 题号 | 题目 | 步骤 |
|------|------|------|
| 509 | 斐波那契数 | 先写暴力递归，发现 fib(3) 算两遍，加备忘录 |
| 70 | 爬楼梯 | dp[i] = dp[i-1] + dp[i-2]，就是斐波那契 |
| 198 | 打家劫舍 | 选当前 + dp[i-2]，或不选 + dp[i-1] |
| 322 | 零钱兑换 | 完全背包，先暴力递归，再改 DP |

**今天重点**：先写暴力递归，看到重复子问题再上 DP。

## Day 8：动态规划进阶 —— 背包与股票

**目标**：掌握"状态定义"和"状态转移方程"的套路。

**DP 三步法**：
1. 定义状态：dp[i] 或 dp[i][j] 代表什么（用嘴说出来）
2. 转移方程：dp[i] 怎么从之前的状态推出来
3. 初始化：边界条件是什么

**习题**：

| 题号 | 题目 | 状态定义 |
|------|------|----------|
| 416 | 分割等和子集 | 0/1 背包：能否凑出 sum/2 |
| 1143 | 最长公共子序列 | dp[i][j]：s1[0..i] 和 s2[0..j] 的 LCS |
| 300 | 最长递增子序列 | dp[i]：以 nums[i] 结尾的最长长度 |
| 53 | 最大子数组和 | dp[i]：以 i 结尾的最大和，或贪心 |
| 121 | 买卖股票的最佳时机 | 一遍遍历，记录最小价格 |

**今天重点**：DP 题不要硬背公式，背"故事"——比如打家劫舍背"偷了 i 就不能偷 i-1"。

## Day 9：二分查找与贪心 —— 查漏补缺

**目标**：二分不是写 mid = (l+r)/2，而是"排除法"思维。

**核心知识点**：
- 二分查找本质：每次排除一半不可能的区间
- 左闭右闭区间：while left <= right，left = mid + 1，right = mid - 1
- 旋转数组：先判断哪半边有序，再决定去哪边
- 贪心：每一步选局部最优，最终得到全局最优（需要证明或直觉）

**习题**：

| 题号 | 题目 | 套路 |
|------|------|------|
| 704 | 二分查找 | 基础：左闭右闭区间 |

| 153 | 寻找旋转排序数组中的最小值 | 比较 mid 和 right |
| 55 | 跳跃游戏 | 贪心：维护最远可达距离 |
| 56 | 合并区间 | 排序后，比较当前左和上一个右 |
