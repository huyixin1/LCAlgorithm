**1. 两数之和**（做对了，但 dict 机制混淆）

**128. 最长连续序列**（✅ 9/14 复习毕业）
- **错误原因**：完全不知道思路，看不懂答案；不会分析复杂度
- **正确思路**：全部数字放进 HashSet。**只从序列起点开始数**：`if x - 1 not in set` 时 x 才是某段连续序列的最左端。为什么剪枝？x-1 存在说明 x 在别人序列的中段，从它数出来的序列一定被截短，数了也白数。起点确定后，`while x + 1 in set` 不断计数，更新全局最长

- **9/14 批改**：顺利独立解决 ✅；时间复杂度曾写错，现已明确"每个元素最多遍历两次 = O(n)"

**15. 三数之和**（🔄 去重逻辑仍不会，当前重点）
- **错误原因**：思路方向对（固定一位 + 找两数和），但漏了双指针的**前提条件：数组必须先排序**；**9/14 复习暴露：去重逻辑不会**——"右侧有两个以上符合条件的数怎么办？"
- **正确思路**：先排序。固定 nums[i]，问题变成在剩余区间找两数和 = -nums[i]。双指针 l=i+1、r=n-1 头尾逼近
- **去重三件套**（9/14 重点讲解）：
  1. 外层固定 i：`if i > 0 and nums[i] == nums[i-1]: continue`（跳过重复的固定值）
  2. 找到一组后：`l += 1; r -= 1` **两边都要动**（只动一边会漏解）
  3. 内层跳过重复：`while l < r and nums[l] == nums[l-1]: l += 1`、`while l < r and nums[r] == nums[r+1]: r -= 1`
- **"右侧有两个以上符合条件的数"怎么办**：不是问题——双指针会**逐个找出所有组合**。比如 [-2,0,0,2,2] 固定 -2 找和为 2：0+2=2 找到一组 → l、r 同时内移跳过重复 → 再找到第二组 [-2,0,2]。双指针的职责就是找出全部，去重只是避免结果里出现相同的三元组
- **为什么必须先排序**：①排序后有序，双指针才能根据 `nums[l]+nums[r]` 与 target 的大小决定移动哪边（像调天平）；②有序让跳过重复变得简单（相邻即相同）
- **所属框架**：双指针（排序 + 双指针 + 去重）
- **复习状态**：🔄 复习中（9/15 重考去重）
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

### 2026-09-12 Day 5 — 二叉树进阶（生病当天 105/106 顺延）

**98. 验证二叉搜索树**（不会区间上下界 → 已默写两法）
- **错误原因**：只会"中序遍历序列严格递增"一种做法；不会**传区间上下界**的递归做法
- **正确思路**（方法 B 区间上下界）：
  - 为什么不能只比较直接孩子？因为 BST 要求**整棵左子树都小于根、整棵右子树都大于根**。只比较 `root.left.val < root.val < root.right.val` 会漏掉跨层约束（例：[5,1,6,null,null,3,7]，3 在 6 的左子树但小于 5）
  - 方法：递归携带 `(lower, upper)` 区间，当前节点值必须在区间内；**往左走时 upper 收紧为当前值，往右走时 lower 收紧为当前值**；根节点区间 (-∞, +∞)，用 None 表示无穷
  ```python
  def isValidBST(root):
      def helper(node, lower, upper):
          if not node: return True
          if lower is not None and node.val <= lower: return False
          if upper is not None and node.val >= upper: return False
          return helper(node.left, lower, node.val) and \
                 helper(node.right, node.val, upper)
      return helper(root, None, None)
  ```
- **方法 A（中序遍历 prev 法）**：中序遍历时维护 prev，`if prev is not None and node.val <= prev: return False`，再更新 prev = node.val。严格递增 = 合法 BST
- **9/14 批改**：看了答案后**默写两种方法各一遍** ✅；自己独立想出来仍需练习 → 9/15 白纸验证默写
- **所属框架**：二叉树（BST 性质 + 区间递归 / 中序 prev）
- **复习状态**：🔄 复习中（9/15 验证默写）
- **三遍刷题法进度**：第一遍✅ 第二遍✅（默写） 第三遍⬜

**230. 二叉搜索树中第K小的元素**（返回值传递断了）
- **错误原因**：思路对（中序遍历计数），但**辅助函数的返回值没有逐层向上传递**——左子树递归找到了答案，这一层没有把它 `return` 出去，导致答案在递归返回途中丢失
- **正确思路**：中序遍历 + 计数，走到第 k 个就返回。**关键：每一层递归都要把子调用的返回值原样 `return` 上去**（返回值链不能断）
  ```python
  def kthSmallest(root, k):
      def inorder(node):
          nonlocal k
          if not node: return None
          left = inorder(node.left)
          if left is not None: return left   # 左子树找到了 → 传上去
          k -= 1
          if k == 0: return node.val         # 当前就是第 k 个
          return inorder(node.right)         # 右子树的答案也要传上去
      return inorder(root)
  ```
- **所属框架**：二叉树（中序遍历 + 递归返回值传递）
- **复习状态**：⬜ 未复习（9/15 考察）
- **三遍刷题法进度**：第一遍✅ 第二遍⬜ 第三遍⬜

**236. 二叉树的最近公共祖先**（节点 vs 子树操作 分不清 → 返回值已懂）
- **错误原因**：**经常不知道应该"对左右子树操作"还是"对当前节点操作"**。把"左右子树的递归结果"和"对单节点的判断"混在一起
- **正确思路**（判断口诀：**答案依赖子树结果 → 后序**）：
  - 问自己："我需不需要先知道左右子树的结果，才能决定当前节点？"需要 → 先递归子树（后序），再处理节点；不需要 → 先处理节点（前序），再递归
  - LCA 属于前者：先递归左右子树，拿到两个返回值后：
    - 左右都找到了 → 当前节点就是 LCA
    - 只有一边找到 → 把找到的那个传上去
    - 当前节点本身就是 p 或 q → 返回当前节点
  - 函数语义："返回这棵子树里找到的目标"
- **9/14 批改**：traverse 函数返回值语义已理解 ✅。**延伸问题**："如果 p、q 不一定在树里怎么办？"（见下）
- **延伸：LCA II 变体（p/q 可能不在树里）**：236 原题保证 p、q 都在树里。若可能不在，加两个全局标志 `found_p / found_q`，遍历时每遇到 p 或 q 置位；后序逻辑不变；最后**检查两个标志是否都为 True**，是才返回找到的节点，否则返回 None
- **所属框架**：二叉树（后序返回值）
